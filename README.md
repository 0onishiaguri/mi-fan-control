# MiFan Control（红米风扇机型拓展控制）

> REDMI K90 Ultra / K90 Max 风扇控制 —— 一个基于Root的第三方散热风扇拓展控制应用。
> 支持四大控制模式、实时转速/温度监控、桌面小组件与智能温控曲线自定义，通知栏实时数据显示等。

---

## 项目简介

MiFan Control 是一个针对 **REDMI K90 Ultra / K90 Max（HyperOS 3.0\4.0）** 开发的第三方散热风扇可视化拓展控制应用。
应用通过 `su` 读写系统风扇底层/sys路径节点，实现对风扇转速的全方位精细监控与自定义随心控制，
同时提供对风扇实时数据的可视化监控、桌面小组件、自定义温控曲线、日志查看与导出等功能，适合对设备散热有精细化可视化需求的玩家与开发者。

> ⚠️ **前置条件**：需要 Root 权限（Magisk / KernelSU 等）；目前仅适配特定机型的风扇节点路径，其他机型请自行适配。

## 功能特性

### 🎛️ 四大控制模式
| 模式 | 说明 |
|---|---|
| **联调模式** | 风扇控制台与系统控制联动，拓展官方散热风扇控制可视化 |
| **底层控制** | 通过直接读写底层/sys路径节点，绕开官方控制的限制，支持无极调速 |
| **智能温控** | 可视化编辑温度-转速分段曲线，按曲线自动调速，支持设置转速每秒步进值 |
| **应用自定义** | 按应用维度设置前台运行时的风扇档位策略 |

### 📊 实时监控
- 温度读取节点可切换（预设多个传感器路径节点），实时读取刷新节点温度数据
- 实时转速显示（rpm）与档位情况（静谧 / 高速 / 狂暴）
- 实时刷新并显示温度-转速历史曲线图

### 🔔 常驻服务与守护
- 前台服务常驻，每 2 秒轮询温度/转速并同步通知与小组件
- **看门狗守护**：服务异常时自动拉活，确保风扇策略持续生效
- **息屏停转**：屏幕关闭时可自动停转降噪
- **充电狂暴**：充电状态下自动提升散热策略

### 🧩 桌面小组件
- 实时展示转速/温度/当前档位数据
- 设有四个快捷风扇档位控制按钮

### 📋 其他
- 日志记录与一键导出
- 权限检测与 Root 环境诊断
- 自定义壁纸背景（支持高斯模糊卡片）
- 自定义温控曲线全局配置导入和导出

## 构建

```bash
# Debug
./gradlew :app:assembleDebug

# Release（含 R8 混淆与资源收缩）
./gradlew :app:assembleRelease
```

> 需要 Android SDK（`local.properties` 中配置 `sdk.dir`）与 JDK 11+。

## 使用

1. 安装 APK 并授予通知权限；
2. 在系统设置中将应用加入"电池优化白名单"，授予自启动权限（可选，保证常驻）；
3. 授予 Root 权限，进入应用后选择控制模式，切换档位开启散热风扇；
4. 可在高级设置中调整通知/小组件刷新间隔、温度节点等。

## 目录结构

```
app/
├── src/main/
│   ├── java/com/fan/widget/     # 全部 Java 源码（25+ 个类）
│   ├── res/                     # 资源（布局 / 图片 / 动画）
│   └── AndroidManifest.xml
├── build.gradle.kts             # 模块构建配置
└── proguard-rules.pro           # R8 混淆规则
```

**核心类速览**

| 类 | 职责 |
|---|---|
| `FanUtil` | 核心工具：SU 命令执行、节点读写、模式/曲线逻辑、温度缓存 |
| `FanRefreshService` | 常驻前台服务：轮询、通知、小组件同步、看门狗、充电/息屏策略 |
| `HomeFragment` | 主界面：风扇动画、实时数据、模式切换 |
| `SmartCurveEditActivity` / `SmartCurveEditView` | 智能温控曲线可视化编辑 |
| `FanWidget` | 桌面小组件 |
| `LogRecorder` | 环形日志缓冲与导出 |
| `FanSpeedSimulator` | SU 守护进程：稳定读速、保活 |
