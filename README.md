# MiFan Control（红米风扇机型控制台）

> Redmi K90 Ultra / K90 Max 风扇控制 —— 一个基于 Root 的系统级散热风扇控制应用。
> 支持四大控制模式、实时转速/温度监控、桌面小组件与智能温控曲线。

---

## 项目简介

MiFan Control 是一个针对 **Redmi K90 Ultra / K90 Max（HyperOS 4.0）** 开发的散热风扇控制应用。
应用通过 `su` 读写系统风扇节点（`/sys/class/leds/...` 等），实现风扇转速的全方位精细控制，
同时提供实时监控、桌面小组件、温控曲线、日志审计等功能，适合对设备散热有精细化需求的玩家与开发者。

> ⚠️ **前置条件**：需要 Root 权限（Magisk / KernelSU 等）；仅适配特定机型的风扇节点路径，其他机型请自行适配。

---

## 功能特性

### 🎛️ 四大控制模式
| 模式 | 说明 |
|---|---|
| **联调模式** | 风扇控制台与系统控制联动，增强官方风扇控制可视化 |
| **底层控制** | 直接读写底层节点，支持无极调速 |
| **智能温控曲线** | 可视化编辑温度-转速分段曲线，按曲线自动调速 |
| **应用自定义** | 按应用维度设置前台运行时的风扇策略 |

### 📊 实时监控
- 温度节点可切换（多传感器源），实时读取 CPU/主板温度
- 实时转速显示（rpm）与档位判定（静谧 / 高速 / 狂暴）
- 转速历史曲线图（SimpleLineChartView）

### 🔔 常驻服务与守护
- 前台服务常驻，每 2 秒轮询温度/转速并同步通知与小组件
- **看门狗守护**：服务异常时自动拉活，确保风扇策略持续生效
- **息屏停转**：屏幕关闭时可自动停转降噪
- **充电狂暴**：充电状态下自动提升散热策略

### 🧩 桌面小组件
- 桌面小组件实时展示转速/温度/当前模式
- 深色模式自动适配

### 📋 其他
- 日志记录与一键导出（内置 LogRecorder）
- 权限检测与 Root 环境诊断
- 自定义壁纸背景（支持高斯模糊卡片）
- 深浅色主题全量适配
- 首次启动欢迎页（WebView 展示功能介绍）

## 构建

```bash
# Debug
./gradlew :app:assembleDebug

# Release（含 R8 混淆与资源收缩）
./gradlew :app:assembleRelease
```

> 需要 Android SDK（`local.properties` 中配置 `sdk.dir`）与 JDK 11+。

## 使用

1. 安装 APK 并授予通知权限；
2. 在系统设置中将应用加入"电池优化白名单"（可选，保证常驻）；
3. 授予 Root 权限，进入应用后选择控制模式；
4. 可在高级设置中调整通知/小组件刷新间隔、温度节点等。

## 目录结构

```
app/
├── src/main/
│   ├── java/com/fan/widget/     # 全部 Java 源码（25+ 个类）
│   ├── res/                     # 资源（布局 / 图片 / 动画）
│   └── AndroidManifest.xml
├── build.gradle.kts             # 模块构建配置
└── proguard-rules.pro           # R8 混淆规则
```

**核心类速览**

| 类 | 职责 |
|---|---|
| `FanUtil` | 核心工具：SU 命令执行、节点读写、模式/曲线逻辑、温度缓存 |
| `FanRefreshService` | 常驻前台服务：轮询、通知、小组件同步、看门狗、充电/息屏策略 |
| `HomeFragment` | 主界面：风扇动画、实时数据、模式切换 |
| `SmartCurveEditActivity` / `SmartCurveEditView` | 智能温控曲线可视化编辑 |
| `FanWidget` | 桌面小组件 |
| `LogRecorder` | 环形日志缓冲与导出 |
| `FanSpeedSimulator` | SU 守护进程：稳定读速、保活 |
